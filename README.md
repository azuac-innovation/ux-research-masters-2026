# 1.	Ümumi qaydalar.
## 1.1. Fənnin tədrisinin məqsədi.

•	"İstifadəçilərin təcrübəsi araşdırılması" fənninin öyrənilməsində məqsəd:
•	 Bu fənn istifadəçi təcrübəsi (UX) dizaynı və araşdırma metodologiyalarını əhatə edir;
•	İstifadəçilərin təcrübəsi edilməsinin üsul və vasitələrinin öyrətmək;
•	Tələbələr istifadəçi ehtiyaclarını və davranışlarını anlamaq üçün araşdırma üsulları. test metodologiyaları və istifadəçi yönümlü dizayn prinsipləri ilə tanış olacaqlar

## 1.2. Fənnin tədrisinin əsas vəzifəsi.
•	İstifadəçi təcrübəsinin (UX) əsas prinsiplərini və araşdırma metodlarını başa salmaq; 
•	UX dizaynında araşdırmaların əhəmiyyətini göstərmək; Praktiki UX testlərini icra etmək və nəticələri təhlil etmək bacarıqlarını inkişaf etdirmək.. 

## Fənni öyrənən tələbələr aşağıdakıları bacarmalıdırlar:
-	İstifadəçilərin təcrübəsi araşdırılması istifadə etmə qaydaları;
-	İstifadəçilərin təcrübəsi araşdırılması, tapşırıqlarən əlavə edilməsi;
-	Resursların təyin edilməsi və tapşırıqlara bərkidilməsi;
-	Təcrübə araşdırılması, paylaşılması və gedişatın izlənməsi;
-	İstifadəçilərin təcrübəsi araşdırılması monitorinqinin aparılması, hesabatı və bağlanması.

## Fənnin öyrənilməsi nəticəsində tələbələr aşağıdakıları bilməlidirlər:	
-	İstifadəçilərin təcrübəsi araşdırılması konsepsiyalarını; 
-	İstifadəçilərin təcrübəsi araşdırılması kompitensiyaları;
-	Trenddə olan rəqəmsal alətlər üçün olan tətbiqlərini və moddellərini;
-	İstifadəçilərin təcrübəsi araşdırılması sona qədər gedən prosesi nəzarətdə saxlamağı;
-	İstifadəçilərin təcrübəsi araşdırılması hesabatın tərtib edilməsi və təqdim edilməsi.
